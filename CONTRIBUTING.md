# Contributing

Thank you for your interest in Brotherhood.

## How to Contribute

1. Open a GitHub Discussion.
2. Propose ideas and gather feedback.
3. Create or update an RFC.
4. Submit a Pull Request.
5. Participate in review.

## RFC Process

Major changes should be proposed through RFC documents located under:

docs/wiki/RFCs/

## Principles

- Open discussion
- Rough consensus
- Documentation first
- Vendor neutrality

## Code of Conduct

Please be respectful and constructive.
