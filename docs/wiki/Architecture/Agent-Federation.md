# Agent Federation

Federation differs from orchestration.

## Orchestration

```text
                Orchestrator
                      |
      -------------------------------
      |         |          |         |
   Agent     Agent      Agent     Agent
```

## Federation

```text
 Agent ↔ Agent ↔ Agent ↔ Agent
```

## Benefits

- No single point of failure
- Vendor neutrality
- Organizational independence
- Direct collaboration
- Scalability
