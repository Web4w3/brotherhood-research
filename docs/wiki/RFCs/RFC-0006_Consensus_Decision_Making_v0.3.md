# RFC-0006: Consensus and Decision Making

Status: Draft v0.3

## Abstract

This RFC defines how deliberations progress from discussion to decisions.

## Consensus

Consensus means sufficient agreement to proceed.

Consensus does not require unanimity.

## Consensus Types

### Full Consensus
No meaningful objections remain.

### Working Consensus
Most participants support the proposal.

### Expert Consensus
Relevant experts agree.

### Documented Disagreement
Disagreement remains documented while progress continues.

## Decision

A Decision SHOULD include:
- Responsible Owner
- Supporting Proposals
- Decision Rationale
- Remaining Risks
- Timestamp

## Decision Authority

The Deliberation Owner retains final responsibility unless delegated.

## Mission Statement

Consensus supports decisions. Decisions create accountability.
